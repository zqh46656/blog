# Welcome to Marmite

This is your first post!

## Edit this content

Edit `content/posts/welcome.md` to change this post.

## Add more content

Create new markdown files in `content/posts/` for posts or `content/pages/` for pages.

Use `marmite --new "Post Title"` to create a new post, add `-d posts` to place it in the posts folder.

## Customize your site

Edit `marmite.yaml` to change site settings.

Edit the files starting with `_` in the `content` folder to change the layout.

## Deploy your site

Read more on [marmite documentation](https://marmite.blog).
